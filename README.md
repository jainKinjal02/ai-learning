## 🧠 Key ideas so far

- **AI** = software that learns patterns from examples instead of following hand-written rules.
- **LLM** = a "next word guesser" trained on huge amounts of text.
- **Token** = a small chunk of text the model reads and writes (about ¾ of a word).
- **Hallucination** = when the model gives a likely-sounding answer that isn't true.
